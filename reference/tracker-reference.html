How it decides which document wins
RankSourceRule
1Approved canonical doc, reviewed in the last 365 daysWins by default.
2Meet transcript with a recorded decision, last 90 daysNever silently overrides #1. If newer than the canonical doc, it's flagged as a conflict for the owner.
3Working docs and decks (and canonical docs overdue for review)Context only, labeled unapproved.
4Legacy docs, PDFs, exports, drafts untouched 540+ daysOnly if nothing above exists.
5ArchivedExcluded entirely.

Security check: client data shared "anyone with link" is blocked from the index until fixed; client data open company-wide is flagged. Ties within a rank go to the most recently modified doc.

Security: client data shared "anyone with link" is blocked from the Brain until fixed; client data open company-wide is flagged. The server re-runs these rules on the files it receives, so a blocked doc never reaches the model even if a request is tampered with.

There is no vector database. In real Gemini Enterprise, Google's built-in, permission-aware connector index does retrieval; this prototype skips retrieval because ~15 docs fit in one prompt, so the server sends only the approved docs straight into it. The value is in curating what gets connected.
